# QUANT RADAR (Jiankong) - A股/港股/指数/ETF 全资产实时监控终端

![Version](https://img.shields.io/badge/version-2.1.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.10%2B-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

> **QUANT RADAR (Jiankong)** 是专为 A 股与港股投资者打造的轻量级、低延迟、高信息密度的全资产即时监控与情报终端。系统集成了基准指数、高波动热点 ETF、风格题材领衔龙头与周期产业基本盘标的，提供毫秒级价格变动追踪、同花顺问财 (iwencai.com) 标准热点题材洞察、巨潮法定信披与 7x24 财经电报联动。

---

## 🌟 核心特性

### 1. 多层级全资产监控池 (186+ 标的)
- **主要基准指数**：恒生指数、恒生科技指数、上证指数、深证成指、沪深300、创业板指、科创50 等核心宏观风向标。
- **2年热点高波动行业 ETF**：算力 CPO、人形机器人、AI应用传媒、硬科技芯片、创新药、港股科技互联网、大宗战略资源等。
- **11 大高波动题材领衔龙头**：AI语料应用、固态电池与新材料、先进封装与玻璃基板、商业航天与空间卫星、跨境电商与IP经济、自主算力芯片、算力光模块、具身智能、低空经济、创新药出海、战略贵金属等前两家标志性龙头。
- **Terminal 周期产业基本盘**：深度覆盖矿业、通用资源、化工、民爆、造纸、农产品加工等核心制造与资源基础盘。

### 2. 「同类型一排 (Group Swimlanes)」泳道陈列
- **分组排横向并列**：同一题材或同行业标的水平归集于独立泳道行，便于横向比价与板块联动直观对比。
- **板块均幅动态计算**：各板块标题栏实时计算平均涨跌幅，红涨绿跌，支持一键折叠/展开与异动标的快速定位。
- **三重视图自由切换**：支持「⊞ 分组排（默认推荐）」、「▦ 平铺网格」、「▤ 紧凑数据表」无缝切换。

### 3. 同花顺问财 (iwencai.com) 标准题材全景洞察
- **主线深度透视**：提炼最近一周市场热度与资金博弈最前沿的 11 大核心题材。
- **驱动与催化解析**：借鉴同花顺问财口径，清晰标注核心逻辑、资金净流入规模及近期催化事件。
- **头部龙头地位说明**：明确标明各主线龙一、龙二标的在产业链中的护城河、业务定位与实时行情。
- **一键定位联动**：点击全景卡片可直接平滑滚动定位到下方资产矩阵对应的监控泳道并高亮闪烁。

### 4. 三维实时情报雷达 (28% 侧边栏)
- 🚨 **异动预警**：根据设定的涨跌幅阈值（指数通常 1.5%~2%，个股 3%~5%）实时告警，支持自定义阈值调节。
- 📑 **巨潮资讯 (CNINFO)**：官方上市公司法定公告直连解析，支持 PDF 原文一键穿透阅读。
- ⚡ **7x24 全球财经快讯**：毫秒级抓取全球财经电报，智能算法自动高亮命中监控池标的。

### 5. 现代化浅色金融终端设计
- **视觉风格**：采用专业浅色主题，Slate 900 高清晰度字体、纯白卡片结合柔和分割线与微阴影，长时间盯盘舒适护眼。
- **行情总时间戳**：顶部主界面配备全市场价格行情基准日期与动态秒级时间戳，脉冲状态指示灯实时反馈网络连通性。

## 🏗️ 系统架构

```
jiankong/
├── scripts/
│   ├── web_server.py           # FastAPI + WebSocket 后台高频行情与情报推送服务
│   ├── watchlist_manager.py    # 监控池管理核心类 (增删改查、阈值控制、代码规范化)
│   ├── cninfo_client.py        # 巨潮资讯 (CNINFO) 官方法定信披采集客户端
│   ├── realtime_monitor.py     # 实时监控调度与行情轮询引擎
│   └── push_notifier.py       # 多渠道推送集成 (桌面通知/飞书/企业微信/钉钉/Bark)
├── web/
│   ├── index.html              # 现代化金融终端单页 UI
│   ├── style.css               # 终端样式库 (浅色主题、泳道布局、题材洞察卡片)
│   └── app.js                  # 客户端交互、WebSocket 实时流解析与响应式渲染
├── watchlist.json              # 监控标的配置文件 (186+ 资产定义)
├── push_config.json            # 外部推送信道配置文件
├── 启动监控.bat                # Windows 一键启动脚本
├── .gitignore                  # Git 忽略配置
└── README.md                   # 项目工程文档
```

## 🚀 快速启动

### 环境要求
- Python 3.10 或更高版本
- 依赖库：`fastapi`, `uvicorn`, `akshare`, `requests`, `pydantic`

### 安装依赖
```bash
pip install fastapi uvicorn akshare requests pydantic
```

### 启动服务
#### 方式一：一键双击启动 (推荐)
直接双击运行项目根目录下的 `启动监控.bat`。

#### 方式二：命令行启动
```bash
python scripts/web_server.py
```

终端启动后将在本地监听端口 `8765`，在浏览器打开：
👉 **http://127.0.0.1:8765**

## 📡 核心 API 接口

| 路由 | 方法 | 功能描述 |
| :--- | :---: | :--- |
| `/api/quotes` | GET | 获取全监控池资产的最新实时行情、涨跌幅、最高最低与均幅 |
| `/api/themes/summary` | GET | 获取同花顺问财口径最近一周热点题材、风格、概念全景及头部公司实时数据 |
| `/api/alerts` | GET | 获取最新异动触发警报列表 |
| `/api/announcements` | GET | 获取自选标的巨潮官方信息披露公告流 |
| `/api/news` | GET | 获取 7x24 全球财经快讯 (含命中自选池标注) |
| `/api/watchlist/groups` | GET | 获取当前系统中所有的分类与板块分组列表 |
| `/api/watchlist/add` | POST | 动态添加新的监控标的（支持 A股/港股/指数/ETF 自动校验） |
| `/api/watchlist/{code}` | DELETE | 从监控池中移除指定标的 |
| `/api/watchlist/{code}` | PATCH | 修改指定标的的预警阈值、分组或启停状态 |
| `/ws/live` | WebSocket | 高频价格 Tick 与状态广播实时长连接 |
