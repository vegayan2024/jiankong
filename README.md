# QUANT RADAR (Jiankong) - A股/港股/指数/ETF 全资产实时监控终端

![Version](https://img.shields.io/badge/version-2.2.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.10%2B-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

> **QUANT RADAR (Jiankong)** 是专为 A 股与港股投资者打造的轻量级、低延迟、高信息密度的全资产即时监控与情报终端。系统集成了基准指数、高波动热点 ETF、风格题材领衔龙头与周期产业基本盘标的，提供毫秒级价格变动追踪、同花顺问财 (iwencai.com) 标准热点题材洞察、巨潮法定信披与 7x24 财经电报联动。

## 📌 最近更新 (v2.2.0)

本次版本借鉴 [Sequoia-X](https://github.com/sngyai/Sequoia-X)、[a-stock-data](https://github.com/simonlin1212/a-stock-data)、[PanWatch](https://github.com/TNT-Likely/PanWatch) 三个开源项目的成熟模式，重点强化数据链路韧性、预警能力与交易时段感知：

- **📈 历史行情多源降级链 + 本地缓存**（借鉴 Sequoia-X / a-stock-data）
  - 详情页历史 K 线按 **tushare → akshare → baostock → 腾讯** 顺序自动降级获取，单一信源故障不再导致详情页空白；全链路统一**前复权 (qfq)** 口径。
  - 港股/指数/ETF 直连腾讯行情兜底（baostock 不支持港股）。
  - 新增 SQLite 本地 K 线缓存 (`scratch/kline_cache.db`)，7 天内数据直接命中缓存，显著加速重复打开；缓存记录每个数据点的实际来源，可溯源。
  - 借鉴 a-stock-data 为东财估值接口增加限流门控（串行 + 最小间隔 + 随机抖动），杜绝高频封禁。
- **🚨 组合条件预警引擎**（借鉴 PanWatch，纯规则引擎，不依赖 LLM）
  - 支持 `and / or` 组合条件组（如「涨幅 ≥5% 且 换手率 ≥8%」），告别单一涨跌幅阈值。
  - 内置防轰炸门控：单标的默认 30 分钟冷却 + 每日 5 次触发上限，预警状态持久化重启不丢。
  - 完全向后兼容：未配置组合条件的标的自动按原单阈值逻辑等价运行。
- **🕒 首页交易时段徽章**
  - 顶部时间胶囊新增秒级时钟 + **交易时间 🟢 / 非交易时间 🔴** 实时标注（集合竞价 🟡、午间休市 🟡、收盘、周末、法定节假日全覆盖）。
  - 节假日判定基于 baostock 官方交易日历（全年缓存，跨年自动刷新），非简单工作日推断。
- **🛡️ 凭证安全**：新增 `.env` 管理 tushare token，并已加入 `.gitignore` 白名单排除，杜绝密钥入库。
- **🐛 修复**：修复顶部导航栏在高缩放/窄窗口下统计区文字竖排错位的问题，新增三档屏幕宽度自适应。

## 🌟 核心特性

### 1. 多层级全资产监控池 (186+ 标的)
- **主要基准指数**：恒生指数、恒生科技指数、上证指数、深证成指、沪深300、创业板指、科创50 等核心宏观风向标。
- **2年热点高波动行业 ETF**：算力 CPO、人形机器人、AI应用传媒、硬科技芯片、创新药、港股科技互联网、大宗战略资源等。
- **11 大高波动题材领衔龙头**：AI语料应用、固态电池与新材料、先进封装与玻璃基板、商业航天与空间卫星、跨境电商与IP经济、自主算力芯片、算力光模块、具身智能、低空经济、创新药出海、战略贵金属等前两家标志性龙头。
- **Terminal 周期产业基本盘**：深度覆盖矿业、通用资源、化工、民爆、造纸、农产品加工等核心制造与资源基础盘。

### 2. 「同类型一排 (Group Swimlanes)」泳道陈列
- **分组排横向并列**：同一题材或同行业标的水平归集于独立泳道行，便于横向比价与板块联动直观对比。
- **板块均幅动态计算**：各板块标题栏实时计算平均涨跌幅，红涨绿跌，支持一键折叠/展开与异动标的快速定位。
- **三重视图自由切换**：支持「⊞ 分组排（默认推荐）」、「▦ 平铺网格」、「▤ 紧凑数据表」无缝切换。

### 3. 同花顺问财 (iwencai.com) 标准题材全景洞察
- **主线深度透视**：提炼最近一周市场热度与资金博弈最前沿的 11 大核心题材。
- **驱动与催化解析**：借鉴同花顺问财口径，清晰标注核心逻辑、资金净流入规模及近期催化事件。
- **头部龙头地位说明**：明确标明各主线龙一、龙二标的在产业链中的护城河、业务定位与实时行情。
- **一键定位联动**：点击全景卡片可直接平滑滚动定位到下方资产矩阵对应的监控泳道并高亮闪烁。

### 4. 三维实时情报雷达 (28% 侧边栏)
- 🚨 **异动预警**：根据设定的涨跌幅阈值（指数通常 1.5%~2%，个股 3%~5%）实时告警，支持自定义阈值调节。
- 📑 **巨潮资讯 (CNINFO)**：官方上市公司法定公告直连解析，支持 PDF 原文一键穿透阅读。
- ⚡ **7x24 全球财经快讯**：毫秒级抓取全球财经电报，智能算法自动高亮命中监控池标的。

### 5. AIHOT 驱动的「行业信息」独立栏目 (新特性)
- **多源产业情报抓取与公众号矩阵**：覆盖中国化工报官方微信、中国有色金属报官方微信、中国黄金报官方微信、中国爆破行业协会官方微信、工信微报、SMM有色大宗、百川盈孚、TrendForce集邦咨询、高工机器人等 25+ 权威信源与官方微信公众号矩阵。
- **四大核心板块置顶锁定**：在全部板块视图中严格固定：1. 化工 -> 2. 有色金属 -> 3. 战略贵金属 -> 4. 民用爆炸与工程 (民爆)，其余板块按热度与冲击力倒序排列。
- **板块实时数量角标**：板块分类按钮后纯粹展示真实抓取到的条数（如 `🧪 化工 (5)`、`💥 民爆 (1)`），不显示虚假排名数字。
- **AI/规则双重价值打分**：从信源权威度 (1-10分) 与产业链商业冲击度 (1-10分) 自动精选高质量事件，对官方微信公众号文章赋予专属权威评级与高亮标签。
- **100%客观保真铁律**：严禁凭空创造和臆想数据，扫描不到新信息时如实告知，绝不添加虚构假数据。
- **每日行业早晚报生成**：归纳提炼结构化核心要点、催化逻辑与受影响核心标的链条。
- **标的穿透直达联动**：行业要闻自动命中自选标的，点击股票胶囊可一键原地切回资产监控并平滑滚动高亮定位。

### 6. 现代化浅色金融终端设计
- **视觉风格**：采用专业浅色主题，Slate 900 高清晰度字体、纯白卡片结合柔和分割线与微阴影，长时间盯盘舒适护眼。
- **行情总时间戳**：顶部主界面配备全市场价格行情基准日期与动态秒级时间戳，脉冲状态指示灯实时反馈网络连通性。

## 🚀 快速启动

### 环境要求
- Python 3.10 或更高版本
- 依赖库：`fastapi`, `uvicorn`, `akshare`, `tushare`, `baostock`, `requests`, `pydantic`, `python-dotenv`

### 安装依赖
```bash
pip install fastapi uvicorn akshare tushare baostock requests pydantic python-dotenv
```

### 配置数据源凭证 (可选)

历史行情首选 tushare，请在项目根目录创建 `.env` 并填入 token（该文件已被 `.gitignore` 排除，不会提交到版本库）：

```bash
TUSHARE_TOKEN=你的token
```

未配置时历史行情自动使用 akshare / baostock / 腾讯等免凭证信源，功能不受影响。

### 启动服务
#### 方式一：一键双击启动 (推荐)
直接双击运行项目根目录下的 `启动监控.bat`。

#### 方式二：命令行启动
```bash
python scripts/web_server.py
```

终端启动后将在本地监听端口 `8765`，在浏览器打开：
👉 **http://127.0.0.1:8765**

## 📡 核心 API 接口

| 路由 | 方法 | 功能描述 |
| :--- | :---: | :--- |
| `/api/quotes` | GET | 获取全监控池资产的最新实时行情、涨跌幅、最高最低与均幅 |
| `/api/themes/summary` | GET | 获取热点题材、风格、概念全景知识库及头部龙头实时盘口与时效指标 |
| `/api/themes/refresh` | POST | 触发风格题材真实周度表现、资金流向与问财热度重新计算并同步监控池 |
| `/api/alerts` | GET | 获取最新异动触发警报列表 |
| `/api/announcements` | GET | 获取自选标的巨潮官方信息披露公告流 |
| `/api/news` | GET | 获取 7x24 全球财经快讯 (含命中自选池标注) |
| `/api/watchlist/groups` | GET | 获取当前系统中所有的分类与板块分组列表 |
| `/api/watchlist/add` | POST | 动态添加新的监控标的（支持 A股/港股/指数/ETF 自动校验） |
| `/api/watchlist/{code}` | DELETE | 从监控池中移除指定标的 |
| `/api/watchlist/{code}` | PATCH | 修改指定标的的预警阈值、分组或启停状态 |
| `/ws/live` | WebSocket | 高频价格 Tick 与状态广播实时长连接 |

## 🧩 本地工程技能库与 AI Agent 约束规范

项目内 `.agents/skills` 与 `.claude/skills` 已配备专属开发与运维技能：
- **`fastapi-templates`**：FastAPI 异步生命周期管理（Lifespan）、WebSocket 连接池保活心跳、异常熔断与多线程行情轮询解耦。
- **`pydantic-models-py`**：规范 186+ 监控标的行情快照、异动预警结构体、AIHOT 行业要闻及巨潮公告的严格数据契约。
- **`kpi-dashboard-design`**：优化泳道视图（同类型一排）、板块均幅实时动态着色、阈值告警触发及高频 DOM 渲染防抖。
- **`pdf-official`**：配合 `cninfo_client.py`，实现巨潮法定公告 PDF 关键财务指标与业绩变动表格的本地极速抽取。
- **`risk-metrics-calculation`**：单票与板块波动率、最大回撤、异动偏离度等风控指标计算。

**全局网页交互自动化优先顺位**：第一顺位 `ego(lite)`，第二顺位 `huashu-chrome`。
